# Import receptury z ChatGPT

1. W Mojej kuchni otwórz dział, wybierz **Import receptury z ChatGPT**
   i kliknij **Kopiuj wytyczne do zdjęcia**.
2. Wklej wytyczne w ChatGPT i dołącz zdjęcie przepisu.
3. Sprawdź odczytane składniki, ilości i kroki w podglądzie. Jeśli ChatGPT
   udostępni edytowalny formularz, popraw pola i zatwierdź. Przy podglądzie
   w wiadomości wpisz poprawki w rozmowie. Gdy przepis jest gotowy, napisz
   **Zatwierdzam**, a potem **Kopiuj recepturę**, żeby otrzymać sam zatwierdzony JSON.
4. Po zatwierdzeniu skopiuj sam JSON. Przy bloku kodu użyj przycisku
   **Kopiuj** przy tym bloku.
5. Wróć do Mojej kuchni i kliknij **Importuj ze schowka**. Jeśli iOS poprosi
   o zgodę na wklejenie, zatwierdź ją. Jeśli przeglądarka odmówi dostępu
   do schowka, wklej JSON w wyświetlone pole. Lista składników i kroki pojawią
   się automatycznie w szkicu.
6. Aplikacja otworzy edytowalny szkic. Możesz jeszcze wprowadzić poprawki
   i wybrać dział. Przepis trafi do książki po kliknięciu **Zapisz przepis**.
